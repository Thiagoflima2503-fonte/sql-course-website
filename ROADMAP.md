## 🚀 Roadmap 2024-2025

### **Q4 2024 - Fase 1: Experiência do Usuário**

- [ ] **Hero Image Otimizada**
  - Gerar imagem profissional com DALL-E 3
  - Testar 3 variações (persona, abstract, data visualization)
  - Medir impacto em CTR

- [ ] **Google Analytics Integração**
  - Rastrear eventos de clique em CTA
  - Monitorar scroll depth e time on page
  - Dashboard com métricas principais (CTR, CPC, Conversion)

- [ ] **Email Capture**
  - Formulário simples (nome + email)
  - Integração com email marketing (Mailchimp ou similar)
  - Automação: Enviar boas-vindas + preview gratuito

- [ ] **Social Proof Dinâmico**
  - Timer de "últimas compras" (últimos 24h)
  - Pop-up de notificação de compra
  - Contador de alunos ativos

### **Q1 2025 - Fase 2: Conversão Avançada**

- [ ] **A/B Testing de Headlines**
  - Testar 3 variações de hero headline
  - Testar 3 variações de CTA copy
  - Rodar por 2 semanas, medir ROAS

- [ ] **Dark Mode Toggle**
  - Sistema de tema claro/escuro
  - Preferência salva em localStorage
  - Transições suaves

- [ ] **FAQ Melhorado**
  - Busca em tempo real (filtro por keyword)
  - Categorias de perguntas
  - Voto de utilidade (Was this helpful?)

- [ ] **Testimonials Carousel Avançado**
  - Vídeos de depoimentos (upload local)
  - Avaliação com stars animadas
  - Filtro por tema (Carreira, Salário, Técnico)

### **Q2 2025 - Fase 3: Conteúdo e Comunidade**

- [ ] **Blog Integrado**
  - 4 artigos iniciais sobre SQL + PostgreSQL
  - SEO otimizado (meta tags, schema markup)
  - Link building com blog posts

- [ ] **Suporte a Múltiplos Idiomas**
  - Português (pt-BR) ✅
  - Inglês (en-US)
  - Espanhol (es-ES)
  - Seletor de idioma no header

- [ ] **Sistema de Feedback**
  - Formulário "Deixe seu feedback"
  - Integração com email ou Notion
  - Widget flutuante discreto

- [ ] **Comunidade/Discord Link**
  - Badge "Comunidade"
  - Integração com Discord servidor do curso
  - Chat preview na página

### **Q3 2025 - Fase 4: Recursos Premium**

- [ ] **Página de Currículo**
  - Showcase completo de módulos
  - Descrição expandida de cada capítulo
  - Recursos adicionais (PDFs, exercícios)

- [ ] **Sistema de Referência**
  - Gere link único para compartilhar
  - Rastreie conversões por referência
  - Dashboard de earnings (comissão)

- [ ] **Payment Gateway Expansion**
  - Adicionar PIX como opção
  - Suportar múltiplos gateways (Stripe, Pagar.me)
  - Parcelamento em 3x, 6x

- [ ] **Certificado Digital**
  - Gerador de certificado ao completar curso
  - Download em PDF personalizado
  - Validação online (código único)
